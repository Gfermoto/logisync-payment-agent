# Как другой клиент ЮKassa подключает агента

Краткая инструкция для слайда защиты и критерия «настройка для другого клиента».

1. Создайте (или возьмите) магазин в ЮKassa. Для знакомства — **тестовый**.
2. В личном кабинете выпустите **токен MCP** (это не `shopId` и не секретный ключ API).
3. Склонируйте этот репозиторий.
4. Скопируйте `.env.example` → `.env`, вставьте:
   - `YOOKASSA_MCP_TOKEN=…`
   - ключ LLM (`OPENAI_API_KEY` / совместимый endpoint)
5. Запустите чат-агента (команда появится в README после 05.12).
6. Проверьте, что агент видит tools MCP (`create_payment`, `get_payment`, …).
7. Опционально: укажите свой read-only источник заказов или используйте `fixtures/`.

Секреты только в `.env`. В git не коммитить.
