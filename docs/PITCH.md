# Pitch draft — LogiSync Payment Agent (трек 1)

Черновик до окна хакатона. Финальные слайды и цифры — 5–6.12.

## 1. Проблема

Продавец LogiSync тратит время на кабинет ЮKassa: доплаты, ссылки, «оплатил ли покупатель», сверка возвратов. Ошибки = отгрузка без денег или потерянные возвраты.

## 2. Решение

ИИ-агент в чате: решает шаг и вызывает **MCP ЮKassa** (`create_payment` / `create_invoice`, `get_payment`, `get_refunds_list`). LogiSync даёт контекст заказа. Возврат денег — только человек.

## 3. Демо (скрипт защиты)

1. «Доплата 790 ₽ по заказу …» → ссылка MCP.  
2. «Проверь оплату» → статус succeeded → «можно отгружать».  
3. «Сверь возвраты» → расхождение с фикстурой → рекомендация.

## 5. Почему MCP, а не только API

Агент работает через стандарт tools MCP: тот же контур, что Cursor/Claude. Другой клиент ЮKassa подключает свой MCP-токен без нашей платёжной интеграции с нуля.

## 6. Что не сдаём

Ядро LogiSync, секреты, классический биллинг подписки платформы — вне этого репо.
